Тлумач — безкоштовна програма для перекладу Unity-ігор українською: знаходить тексти в ассетах, дає їх редагувати таблицею, будує шрифти з кирилицею й повертає переклад у гру (оригінали зберігаються).

**Як встановити**
1. Завантажте `Tlumach-VERSION.zip` нижче й розпакуйте його повністю в будь-яку папку.
2. Запустіть `Tlumach.exe`. Потрібні Windows 10/11 (64-біт) і [.NET Runtime 8](https://dotnet.microsoft.com/download/dotnet/8.0) x64 або новіший.
3. Програма ще не підписана, тож Windows може показати SmartScreen: «Докладніше» → «Виконати в будь-якому разі».
